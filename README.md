# TN-election-analysis
SQL and Power BI project analyzing Tamil Nadu election data to identify voting trends, party performance, candidate rankings, and constituency-wise vote distribution through interactive dashboards and data visualization.

# Tamil Nadu Election Analysis Dashboard

## Project Overview
This project analyzes Tamil Nadu election data using SQL, MySQL, and Power BI to identify voting trends, party performance, candidate analysis, and constituency-wise vote distribution.

## Tools Used
- SQL
- MySQL
- Power BI
- Excel

## Key Analysis
- Party-wise vote distribution
- Vote share analysis
- Top candidates by votes
- Constituency-wise vote analysis

## SQL Concepts Used
- SELECT
- GROUP BY
- ORDER BY
- Aggregate Functions
- Window Functions

## Dashboard Features
- Interactive slicers
- KPI cards
- Party performance charts
- Constituency analysis
- Candidate ranking visuals
